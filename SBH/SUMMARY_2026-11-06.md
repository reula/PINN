# SBH: what was tried, 17 Oct - 6 Nov 2026, and how it did

Single Brill-Lindquist puncture (m = 0.5), vacuum CCZ4, r <= 24, windows of 0.25. Graded against the 1D
reference (finite-difference evolution, dr = 0.005) and the Misner-Sharp mass m/M - 1. **Rule used here:
differences below a factor 2 count as "alike".** Details, numbers and plots: `README.md`, section 7 for the
`sing_*` work; `HANDOFF.md` is the map.

## 1. Speed and optimisers (17 - 21 Oct, collaborators' 3D code)

| item | result | verdict |
|---|---|---|
| `--deriv_mode taylor` (batched 2nd-order forward pass) | residual + gradient 1.75x faster on the A30, agrees to 1e-15 | better, default |
| `--qn_fixed_batch` (QN on a fixed sample) | held-out loss 50-330x worse (overfits) | worse |
| QN then 12 DSGNAR iterations (`fork15_dsg`) | 2-7x worse in 9 of 10 windows | worse |
| Pure DSGNAR / Gauss-Newton (`w8_gn`, `_scan`, `_exact`) | trust region collapses; ~1e4 above SSBroyden; mass error 0.50 vs 1.1e-2 | worse, dropped |
| Crunch scale-invariant QN (`--qn_scale_invariant 1`) | fixes the Hessian freezing in the authors' test | default; not measured in runs |

## 7. The puzzle: does the reference minimise the loss?

1. **Yes, where it matters.** Evaluated as a function (the reference's nodes interpolated with degree-5
   polynomials, derivatives of the interpolant), the reference's residual for r >= 1 is 10^5 - 10^11 below the
   PINN's in every window, as a 4th-order scheme at dr = 0.005 should give. Inside r = 1 it is NOT smaller: in
   r = 0.05-1 it is alike the PINN's or up to 4x above (window 16), in r = 0.01-0.05 alike or up to 140x above
   (window 31). Time interpolation of degree 3 gives the same numbers, so the snapshot spacing (0.025) does not
   limit this.
2. **The fitted networks were the problem, not the reference.** A network fitted pointwise to 1e-4 has the
   right values but wrong derivatives (small wiggles); the residual is made of first and second derivatives,
   so it is 10^3 - 10^6 x larger. Fitting r f' and r^2 f'' too did not cure it (and the time derivative was
   never fitted).
3. **Why the PINN's error stays at 1e-4 although its loss is 1e-8.** The loss is a mean of SQUARED residuals:
   1e-8 at r >= 1 means an rms residual of 1e-4 there, the same size as the outer field errors; the reference
   has an rms residual below 1e-6 there and stays accurate. Near the puncture the picture differs: the
   reference has as large a residual as the PINN inside r = 1 and yet no error worth the name, which fits
   that this region lies inside (or near) the horizon, where errors cannot reach the exterior. So the loss
   that sets the outer error is the outer part, and the PINN would need it near 1e-12 (1e4 below where it
   saturates) for 1e-6 errors. Not yet checked: where the horizon sits in these coordinates at late times.
4. Two things that could also separate PINN and reference without any residual: the outer boundary (the
   reference is the free-space solution with its boundary at r = 60; the PINN imposes Sommerfeld at r = 24),
   and the window hand-offs (each window starts from the previous network, not from the exact data). Both are
   untested as error sources.
5. Inside r = 0.01 neither has a small residual (reference 1e-3 - 6e2, PINN 2e-2 - 4e2): the grid has only two
   nodes there, the chi floor (1e-5) acts, and the clouds put no points there. Putting points there
   (`log25`) hurt.
